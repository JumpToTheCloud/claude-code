The structure

A new component gets this tree, one branch per repository, with the same name as its Jira Component:

Components
└── <component>
    ├── <component> — Overview
    ├── <component> — PRDs
    │   └── PRD: <title>
    │       ├── Technical Plan — <title>
    │       └── Consistency Analysis — <title>
    ├── <component> — Decisions        ADRs of this component
    ├── <component> — Design           architecture, diagrams
    └── <component> — Runbooks         operation and how-tos

How to create it

  1. Create the Jira Component in project JTTC with the component name.

  2. Run the confluence-create-component skill with the component name, repository, owner, stack and purpose. It creates the six pages and fills the Overview. Copying this page does not work: a copy does not bring the child pages.

  3. Complete the sections of the Overview that the skill leaves with a prompt.

PRDs, ADRs and runbooks are not part of the tree: create them with confluence-create-doc when needed. See How this space works.
