ADRs that affect only this component. A decision that affects several components goes in Platform → Decisions.

Rules

  • Title: ADR-NNNN: short imperative title. Numbering is per component, consecutive, starting at 0001, and numbers are never reused.

  • Create ADRs with the confluence-create-doc skill. The state is the status lozenge of the summary table: PROPOSED, ACCEPTED or SUPERSEDED.

  • Never rewrite history: supersede with a new ADR, set the old one to SUPERSEDED and link both ways.
