What was specified, and why. One child per PRD, titled PRD: <title>. Each PRD has two children of its own: Technical Plan — <title> and Consistency Analysis — <title>.

Rules

  • Create these pages with the confluence-create-doc skill, never by hand. A PRD has no number: it is identified by its page, which keeps its ID when it is renamed.

  • The state of a PRD or a plan is the status lozenge of its summary table: DRAFT, IN REVIEW, APPROVED or SUPERSEDED.

  • A PRD usually leads to one Jira Epic. That is the common case and not an obligation: some PRDs produce several Epics, some produce only Stories.

  • Link the Epic in the PRD summary table, and link the PRD from the Epic.

  • When a PRD is replaced, set its status to SUPERSEDED, point to its replacement and move it to Archive.
